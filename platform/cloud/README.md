# Kalix Code Cloud source

هذا المجلد هو مصدر **Kalix Code Cloud**: صفحة عامة عربية، مساحة مزوّدات نماذج محمية، ومساحة GitHub لإدارة مستودعات المستخدم بعد المصادقة. النسخة المُدارة المنشورة متاحة عبر <https://kalixcode-lvx9ubmm.manus.space>.

## محتوى المصدر

| المسار | الغرض |
|---|---|
| `client/` | واجهة React/Vite العربية المتجاوبة للحاسوب والهاتف |
| `server/` | إجراءات tRPC المحمية، وتشفير مفاتيح المزوّدات ورموز GitHub |
| `drizzle/` | مخطط قاعدة البيانات وترحيلات المزوّدات واتصال GitHub |
| `KALIX_CODE_GUIDE.md` | دليل تشغيل وإدارة المزوّدات والنماذج وGitHub |
| `DEPLOYMENT.md` | ملاحظات الاستضافة والنطاق الثابت |

## حدود التشغيل المحلي

لا يحتوي هذا المجلد على أي ملف `.env` أو أسرار أو بيانات إنتاج. يحتاج تشغيله خارج بيئة الاستضافة المُدارة إلى قاعدة بيانات MySQL/TiDB، وإعداد OAuth، ومتغيرات خادمية مثل `DATABASE_URL` و`JWT_SECRET`. لهذا لا يُعد مسار Termux المحلي في [`docs/termux.md`](../../docs/termux.md) بديلاً لتشغيل تطبيق Cloud؛ استخدمه لتشغيل **Kalix CLI** المحلي فقط.

## الضوابط المطبقة

رموز GitHub ومفاتيح مزوّدي النماذج تُشفّر خادميًا ولا تعود إلى المتصفح بعد الحفظ. قراءة المستودعات وتعديل ملف تتطلبان اتصال GitHub الخاص بالمستخدم المصادق، ولا تُنشأ عملية commit إلا بعد تأكيد صريح. لا يختلق Kalix تسعير النماذج؛ فالتمييز المجاني/المدفوع يحدده مالك الحساب.
